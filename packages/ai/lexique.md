# Lexique darija / filière (enrichissable par Fares)

Messages en darija tunisienne écrite en lettres latines, mélangée de français et d'anglais.
Chiffres pour certaines lettres arabes : 3 = ع, 7 = ح, 9 = ق, 5 = خ, 2 = ء.

## Temps

- lyoum = aujourd'hui ; ghodwa = demain ; ba3d ghodwa = après-demain ; lbera7 = hier
- « <jour> hedha » / « <jour> jey » : NE CALCULE PAS la date, rapporte « jour » + « proximite » (+ « passe » si le verbe est au passé) ; le code applique la règle de Fares
- el semaine jeya = la semaine suivante ; el semaine hedhi = cette semaine
- jours : lithnin / ltnin (lundi), thletha (mardi), larb3a (mercredi), lkhmis (jeudi), ljom3a (vendredi), sebt (samedi), l7ad (dimanche)
- sbe7 = le matin ; la3chiya = l'après-midi ; lil = la nuit

## Mots fréquents

- 9al / 9alet = il / elle a dit ; mta3 = de ; fama = il y a ; ma fammech = il n'y a pas
- lezem = il faut ; nab3thou = on envoie ; yab3thou = ils envoient ; ab3ath = envoie
- valid = validation ; prés = présentiel ; en ligne / online / meet / teams = à distance
- tafi / annuli = annulé ; t2ajel / reporté = reporté ; rattrapage = séance de rattrapage
- compte rendu / CR / rapport = document à rendre ; énoncé = sujet du TP ou du devoir

## Groupes

- La filière RT4 a deux groupes : **RT4/1** (celui de Fares) et **RT4/2**. Sans précision : toute la filière (RT4).
- Formulations du groupe 1 : RT4/1, RT4-1, RT4 1, RT41, RT4 G1, G1, grp 1, grp1, gr 1, groupe 1, 1er groupe, premier groupe, lgroupe lowel, ajroupe 1
- Formulations du groupe 2 : RT4/2, RT4-2, RT4 2, RT42, RT4 G2, G2, grp 2, grp2, gr 2, groupe 2, 2ème groupe, 2e groupe, deuxième groupe, lgroupe theni, ajroupe 2
- Sous-groupes : 1_1, 1_2 (RT4/1) ; 2_1, 2_2 (RT4/2). Fares est en 1_2 (PRM).
- « RT4/1 … le 12, RT4/2 … le 13 » = deux informations : une par groupe.

## Matières (abréviations)

STR, PRM, THD, RHD, PU, TNS, ML, FW (Frameworks), GF (Gestion financière), ANG (Anglais), COM (Communication), Droit.
